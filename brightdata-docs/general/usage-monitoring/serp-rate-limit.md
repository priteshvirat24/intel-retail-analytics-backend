# SERP fair usage: rate limit

> Bright Data SERP API fair usage policy: where to find the rate limit applied to your zone, HTTP 429 behavior, and how to request an increase.

Starting January 2026, Bright Data is applying a rate limit to its SERP services.

To see the rate limit currently applied to your zone, open the Control Panel, select the zone, then go to the Overview tab > Access details.

Unfunded accounts are subject to a rate limit of 1,000 req/min.

Upon breaching the rate limit, an HTTP error 429 will be returned. If you wish to extend the rate limit, add funds to your account or contact your sales agent.

# Event log

> How to read the Bright Data event log in the Zones dashboard to monitor recent proxy requests, IP usage, and zone activity at a glance.

For a quick overview of your usage, go to the event sign in your Zones page:

  <img src="https://mintcdn.com/brightdata/jeaQWxFKde5jgPN8/images/general/usage-monitoring/event_log/event-log-1.png?fit=max&auto=format&n=jeaQWxFKde5jgPN8&q=85&s=04e303ef2e5ec6723d7b7a2c4e791559" alt="event-log-1.png" width="1644" height="214" data-path="images/general/usage-monitoring/event_log/event-log-1.png" />
</Frame>

The event log will show you one line of data for the first request made with each unique IP in the past hour.

The presented data is:

* **Date:** Time and date of the request
* **Zone:** What Zone was used for the request
* **Source IP:** What IP the request was made from
* **URL:** The target site of the request
* **Result:** Success or Fail of the request

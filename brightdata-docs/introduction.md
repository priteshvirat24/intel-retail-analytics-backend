# Welcome to Bright Data

> Bright Data's web data platform: residential, mobile and ISP proxies, 1000+ pre-built scrapers, a dataset marketplace and AI-ready APIs.

Bright Data is a web data platform that helps you collect, process and scale access to public web data. It brings a 400M+ IP proxy network, 1000+ pre-built scrapers, ready-made datasets and AI-ready APIs together under one account, so you can focus on using data instead of building and maintaining scraping infrastructure.

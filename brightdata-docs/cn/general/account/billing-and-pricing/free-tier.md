# 免费套餐

> 每个新 Bright Data 账户每月可获得 5,000 个免费信用额度，适用于 Web Unlocker API、SERP API、Web Scraper API、Scraper Studio 和 Browser API。无需信用卡。

每个新 Bright Data 账户每月可获得 **5,000 个免费信用额度**（约 \$7.50 价值），可用于 Web Unlocker API、SERP API、Web Scraper API 和 Scraper Studio。无需信用卡，无需促销码，无需承诺。

**自 2026 年 9 月 1 日起，Browser API 也包含在每月免费信用额度中。** Browser API 每 1 MB 流量消耗 5 个信用额度，因此将全部 5,000 个信用额度用于 Browser API 时，每月可获得近 1 GB 的免费流量。

## 什么是 Bright Data 免费套餐？

免费套餐是一种每月循环发放的信用额度，自动适用于每个新账户。信用额度在每月 1 号续期，并从单一共享池中扣除，因此您可以将其用于符合条件产品的任意组合。Web Unlocker API、SERP API 和 Web Scraper API 每次请求或每条记录消耗一个信用额度。Scraper Studio 从同一池中扣除，每次页面加载消耗一个信用额度。自 2026 年 9 月 1 日起，Browser API 也从同一池中扣除，每 1 MB 流量消耗 5 个信用额度。

Bright Data 采用**预付钱包模式**：您只会因已明确存入的资金而被扣费。免费套餐账户在信用额度耗尽时会硬性停止，绝不会产生意外账单。

## 免费信用额度可用于哪些产品？

| 产品                                                                       | 功能                                                                                                           |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **Web Unlocker API**                                                     | 获取任何网页，自动绕过反机器人保护。                                                                                           |
| **SERP API**                                                             | 从 Google、Bing 等提取结构化搜索结果。                                                                                    |
| **Web Scraper API**                                                      | 通过预构建的、持续维护的抓取器获取热门网站的结构化数据。                                                                                 |
| **Scraper Studio**                                                       | 在云端 IDE 中或借助 AI 智能体构建并运行自定义抓取器。每次页面加载消耗一个信用额度，而非按记录计费。                                                       |
| **[Browser API](/cn/scraping-automation/scraping-browser/introduction)** | 在 Bright Data 的云端浏览器上运行 Puppeteer、Playwright 或 Selenium 脚本，内置解封能力。自 2026 年 9 月 1 日起包含在内，每 1 MB 流量消耗 5 个信用额度。 |

<Note>
  代理产品（数据中心代理、ISP 代理、住宅代理）**不包含**在每月免费信用额度中。新账户可获得单独的一次性 **\$2 试用额度**（有效期 7 天）来测试代理产品，并在添加付款方式后额外获得 **\$5 奖励额度**（有效期 30 天）。
</Note>

## 免费信用额度如何消耗？

免费信用额度从**每个账户 5,000 个信用额度的单一共享池**中扣除。Web Unlocker API、SERP API 和 Web Scraper API 每次请求或每条记录消耗一个信用额度。Scraper Studio 从同一池中扣除，每次页面加载消耗一个信用额度，因此其消耗取决于每个抓取器加载的页面数量。自 2026 年 9 月 1 日起，Browser API 每 1 MB 流量消耗 5 个信用额度，因此其消耗取决于每个浏览器会话传输的数据量。使用量按计量从同一池中扣除，无论是哪个产品发起的调用。

控制面板会实时显示您当前是在使用免费信用额度还是已存入的余额。

<Note>
  Bright Data MCP 服务器的请求也从此池中扣除。每月 5,000 次请求的 MCP 免费套餐就是这同一个共享额度，因为 MCP 服务器运行在 Web Unlocker API 之上。
</Note>

<Note>
  未使用的免费信用额度不会结转到下个月。信用额度在每月 1 号重置为 5,000。
</Note>

## 免费信用额度用完后会发生什么？

根据账户中是否已存入资金，会有两种结果：

* **账户中有资金时：** 使用会按您计划的 PAYG 费率自动切换到预付余额。服务不会中断。
* **账户中无资金时：** 请求将返回错误，您会被提示添加资金以继续使用。

两种情况下，您的 5,000 个免费信用额度都会在下个月 1 号续期。

<Note>
  使用免费套餐（未充值）的账户在 SERP API、Web Unlocker API 和代理产品上的默认速率限制为每分钟 1,000 次请求。您可以在控制面板中查看此限制，路径为该区域的“概览 (Overview)”选项卡 > 访问详情 (Access details)。向账户充值后，此速率限制将自动移除。
</Note>

### 免费信用额度用完后如何保持服务不中断？

在账单设置中启用**自动充值**以确保服务不中断。当您的可用余额低于配置金额的 85% 时，自动充值会触发并自动补齐余额。您可以设置任意金额。在[账单设置](https://www.bright.cn/cp/billing/settings)中进行配置。

## 谁有资格使用免费套餐？

免费套餐适用于**所有新账户**，并在注册时自动应用。

以下账户类型**不**符合条件：

* 使用自定义 PAYG 定价计划的账户
* 使用预付承诺（订阅）计划的账户

<Note>
  如果您升级到预付承诺计划，将不再发放每月循环的免费信用额度。升级时剩余未使用的免费信用额度仍可继续使用。
</Note>

<Note>
  添加信用卡仅作为验证步骤。除非您的免费信用额度耗尽且账户中已存入资金，否则不会扣费。
</Note>

## 如何监控我的免费信用额度使用情况？

直接在控制面板中跟踪您的免费信用额度余额和消耗：

1. 前往[账单概览](https://www.bright.cn/cp/billing/overview)。
2. **免费套餐额度**部分会显示您的剩余额度和下次续期日期。
3. 要设置余额阈值提醒，请前往[账单设置](https://www.bright.cn/cp/billing/settings)。

## 如何为免费套餐账户获取支持？

免费套餐账户可以向 Bright Data 支持团队提交工单，也可以使用 **Sophie**（Bright Data 的 AI 助手）获取帮助。两者均可在控制面板中使用。

## 常见问题

### 5,000 个免费信用额度可以覆盖多少次请求？

对于 Web Unlocker API、SERP API 和 Web Scraper API，一个信用额度等于一次 API 调用，因此您每月的 5,000 个免费信用额度最多可覆盖这三种产品任意组合的 5,000 次调用。Scraper Studio 也从该池中扣除，每次页面加载消耗一个信用额度，因此其信用额度消耗取决于每个抓取器加载的页面数量，而非按记录计费。自 2026 年 9 月 1 日起，Browser API 每 1 MB 流量消耗 5 个信用额度，因此全部 5,000 个信用额度可覆盖 1,000 MB（近 1 GB）的 Browser API 流量。

### 免费信用额度会结转吗？

不会。信用额度在每月 1 号重置为 5,000。未使用的额度会作废。

### 信用额度用完后会自动扣费吗？

不会。如果您没有存入资金，会触发硬性停止，不会产生扣费。如果您有预存资金，使用将按标准 PAYG 费率从余额中扣除。启用[自动充值](https://www.bright.cn/cp/billing/settings)可以自动补充余额。

### 免费套餐可以用于 Browser API 吗？

可以，自 2026 年 9 月 1 日起生效。Browser API 从相同的 5,000 个每月免费信用额度共享池中扣除，每 1 MB 流量消耗 5 个信用额度。若将全部额度用于 Browser API，每月可获得近 1 GB 的免费流量。

### 免费套餐可以用于代理吗？

不可以。数据中心代理、ISP 代理和住宅代理不包含在每月免费信用额度中。注册时可获得单独的一次性 \$2 试用额度用于代理产品，添加付款方式后还可获得额外的 \$5 奖励。

### 免费套餐可以用于 Scraper Studio 吗？

可以。Scraper Studio 包含在每月免费信用额度内，并从相同的 5,000 个信用额度共享池中扣除。在免费套餐中，Scraper Studio 每次页面加载消耗一个信用额度，因此信用额度消耗取决于您的抓取器加载的页面数量，而非按记录计费。

### 升级到预付承诺计划后，未使用的额度会怎样？

升级后每月循环的免费信用额度将停止发放。升级时剩余未使用的额度仍可继续使用。

### 免费信用额度可以与促销码一起使用吗？

可以。免费信用额度会先被消耗。促销码折扣适用于之后的任何 PAYG 使用量。

### 免费套餐之后如何开始使用 PAYG？

在[账单页面](https://www.bright.cn/cp/billing)向账户添加资金。无最低承诺。您保持在 PAYG 计划上，仅为实际使用量付费。

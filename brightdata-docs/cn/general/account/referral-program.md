# 推荐计划

> Bright Data 的推荐计划为您提供了一种简单的方式，通过向他人推荐我们的平台来赚取奖励。无论是向同事介绍，还是向企业推荐 Bright Data，您都可以从您带来的每位客户的收入中获得最高 50% 的分成。本指南将介绍该计划的运作方式、与联盟计划的区别，以及如何立即开始赚取收益。

Bright Data 的推荐计划为您提供了一种简单的方式，通过向他人推荐我们的平台来赚取奖励。以下是该计划的运作方式：

1. **分享您的推荐链接**：加入推荐计划后，您将获得一个专属推荐链接。分享此链接给可能受益于 Bright Data 服务的个人或企业。

2. **赚取佣金**：当有人通过您的链接注册并订阅付费计划时，您将获得佣金。具体而言，您可以获得 50% 的收入分成，每位客户最高可达 \$2,500。

3. **获取账户积分**：或者，您可以选择将奖励以 Bright Data 账户积分的形式领取，并在此选项下额外获得 5% 的奖励。

### 常见问题

* **Bright Data 的推荐计划如何运作？**\
  通过我们的推荐计划，您可以通过分享 Bright Data 赚取奖励。分享您的专属推荐链接后，当被推荐用户注册并消费 \$100 时，您将获得 \$100 账户积分。此外，您还可以获得 50% 的收入分成，每位客户最高可达 \$2,500。

* **我在哪里可以找到我的推荐代码？**\
  注册推荐计划后，您的专属推荐代码将在您的账户仪表板中显示。您可以复制并分享给潜在的 Bright Data 用户。

* **如何通过推荐计划赚钱？**\
  您可以通过以下两种方式赚钱：

  * 当被推荐用户消费 \$100 时，您将获得 \$100 账户积分。
  * 通过 50% 的收入分成，每位客户最高可赚取 \$2,500。

* **我可以追踪我的推荐收益吗？**\
  是的，您可以在 Bright Data 账户仪表板中监控您的推荐进度和收益。

欲了解更多信息或加入推荐计划，请访问我们的[推荐计划页面](https://www.bright.cn/referral/)。

**推荐计划 vs. 联盟计划 – 有何区别？**
如果您想知道推荐计划与 Bright Data 的联盟计划是否相同，答案是否定的。主要区别如下：

* **推荐计划**：适合现有用户，向同事、朋友或企业推荐 Bright Data。您可以通过直接邀请他人注册来赚取奖励。
* **联盟计划**：更适合营销人员、博主和影响者，通过内容、广告或网站向更广泛的受众推广 Bright Data。

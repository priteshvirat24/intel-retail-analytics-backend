# 账户管理常见问题解答

<AccordionGroup>
  <Accordion title="如何重新验证我的账户以解决账单问题？">
    在允许您停用或删除您的 Bright Data 账户之前，必须满足某些要求。如果您无法停用您的账户，请确保满足所有以下条件：

    * **您必须是账户所有者：** 只有最初开立账户的人（“所有者”）才有能力删除它。
    * **它不是 Bright Data 内部账户：** （这主要与内部使用相关，与普通客户无关。）
    * **所有账单必须付清：** 您的账户不得有任何未结款项或未付发票。
    * **真实余额必须正好为零：** 您的账户真实余额应正好为 \$0——没有正余额或负余额。注意：赠金不计入您的真实余额。信用额度——在某些情况下通常被视为“贷款”——可能会被区别对待；请确保您的真实余额根据您的账单部分显示为零。
    * **没有活跃的长期订阅 (LTS)：** 如果您有正在进行的 LTS，则必须在停用您的账户之前取消或完成它。
    * **没有月度承诺：** 任何月度服务承诺必须已完成或取消。
    * **没有待处理费用：** 您的账户不应有任何待处理或未出账单的使用量（“待处理费用”）。有关哪些符合待处理费用的说明，请查看您的账单部分或联系我们的支持团队。

    如果您是账户所有者并且已满足上述所有标准但仍无法停用您的账户，请联系我们的支持团队寻求进一步帮助。如果您的账户被屏蔽，您将立即收到一封电子邮件，解释如何解决问题。请联系您的专属账户经理或 Bright Data 的合规团队：[compliance@brightdata.com](mailto:compliance@brightdata.com)。要恢复您被屏蔽的账户，您需要提供以下信息：

    <Tabs>
      <Tab title="注册公司">
        * 公司注册表格
        * 被标记的付款方式的照片
      </Tab>

      <Tab title="非注册公司">
        * 照片身份证明、驾驶执照或护照
        * 被标记的付款方式的照片
      </Tab>
    </Tabs>
  </Accordion>

  <Accordion title="为什么我的账户因账单问题被暂停？">
    Bright Data 可能会因以下原因之一暂停您的账户（这将阻止对其中任何区域的访问）：

    * 付款方式与个人详情之间存在差异
    * 用户登录的国家/地区与其信用卡所在国家/地区不同
    * 尝试处理被拒绝的付款次数过多
    * 未能使用 3D Secure 验证信用卡付款

    要再次启用您的账户并退出暂停状态，请查看您的账单详情并修复缺失或不正确的信息。一旦恢复计费，您的账户将自动再次激活。如果出于某种原因没有激活，请联系您的账户经理。
  </Accordion>

  <Accordion title="为什么我的账户被禁用？">
    Bright Data 会禁用闲置 12 个月的账户（注意：禁用账户与暂停账户不同）。
    要重新启用您的账户，您需要联系我们的工作人员，可以通过控制面板中的“帮助与支持”部分，或发送电子邮件至 [sales@brightdata.com](mailto:sales@brightdata.com)。
  </Accordion>

  <Accordion title="如何为我的账户设置密码？">
    * 访问 [https://www.bright.cn/cp/setting/auth。](https://www.bright.cn/cp/setting/auth。)
    * 在“设置密码 (Setup a password)”部分，输入您想要的密码。
    * 确保您的密码包含数字、大写和小写字母以及至少一个特殊字符。
    * 重新输入密码以确认。
    * 点击“保存密码 (Save password)”。
    * 如果出现提示，输入您的 2FA 代码以验证操作。
  </Accordion>

  <Accordion title="如何防止我的账户被暂停？">
    如果您的账户因资金不足而被暂停，您随时可以向您的账户充值，暂停将立即解除。

    为确保您的账户永不被暂停，我们强烈建议您使用我们的自动充值选项。可以在您账户的“账单”部分激活它，并确保不间断的服务。当您的可用余额低于总账户余额的 85% 时，自动充值开始生效。设置的金额完全由您决定，可以是任何面额。您可以在[此处](https://www.bright.cn/cp/billing/settings)找到自动充值部分。

  <Accordion title="如何邀请用户加入我的账户？">
    要将用户添加到您的账户，请遵循以下说明：

    1. 导航到[设置页面](https://www.bright.cn/cp/setting/users)
    2. 点击“新用户 (New User)”按钮以启动用户添加过程。
    3. 输入您要邀请的用户详情，例如他们的姓名和电子邮件地址。
    4. 从以下选项中为用户选择权限级别：
       * 管理员 (Admin)：授予对整个账户的访问权限，包括所有设置和配置。
       * 财务 (Finance)：仅限制访问账单和财务页面。
       * 运营 (Ops)：提供对产品的访问权限，但限制账单访问。
       * 限制 (Limit)：允许用户修改区域密码并管理 IP 允许列表/拒绝列表。
       * 用户 (User)：授予 API 使用访问权限，但不允许访问账单或产品页面。
    5. 确认并发送邀请：查看详情，确认权限，然后发送邀请。

    被邀请者将收到一封电子邮件，其中包含根据其权限级别加入和访问账户的说明。

    添加后，新用户将根据授予的权限访问账户。如果需要，您也可以稍后编辑权限。
  </Accordion>

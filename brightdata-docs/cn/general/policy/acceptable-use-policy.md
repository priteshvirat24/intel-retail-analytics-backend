# 可接受使用政策

Bright Data 的平台、技术和网络（统称为“服务”）仅供合法合规目的使用，并受 [Bright Data 主服务协议](https://www.bright.cn/license)的约束。

Bright Data 会并将对非法或不合规使用 Bright Data 服务的行为采取坚定措施，并将协助执法部门调查对 Bright Data 服务的潜在滥用活动。

严禁将 Bright Data 服务用于非法、欺诈或滥用活动。任何此类可疑使用都将受到调查。

被禁止的活动包括但不限于：

* 收集非公开信息（即登录后的数据）
* DDoS 攻击
* 垃圾邮件：大量发布任何邮件/留言板/IRC/评论消息和图片
* 广告欺诈或点击欺诈
* 出于欺诈目的的冒充或欺骗
* 创建虚假账户或内容
* 使用自动购票（抢票机器人）
* 抽奖、彩票或赌博
* 虚假互动（点赞、评论、分享等）
* 游戏或游戏内物品/货币交易
* 未经 Bright Data 事先书面批准转售代理（请参阅我们的 [合作伙伴计划](https://www.bright.cn/partners)）
* 使用流媒体相关域名（视频、音乐或图片流媒体）
* 交易加密/虚拟货币或 NFT
* 任何搜索引擎优化 (SEO) 操纵（例如：搜索引擎结果中的虚假点击）
* 在分类、二手和转售网站（如 Craig's list）上发帖
* 完成调查问卷以换取利益或任何有价值的东西
* 任何违反适用法律或法规或任何第三方权利的活动形式

Bright Data 会主动屏蔽某些网络内容（例如：成人内容、政府网站、有害域名等），具体由 Bright Data 自行全权决定。Bright Data 保留随时自行决定添加或撤回任何网络内容屏蔽的权利。

Bright Data 可能会自行决定限制 Bright Data 服务的使用，以防止对任何第三方计算机或服务造成任何损害或服务中断。Bright Data 对本文所述的任何限制不向客户承担责任。

我们鼓励用户通过我们的专用电子邮件 ([abuse@brightdata.com](mailto:abuse@brightdata.com)) 或我们的报告渠道 ([https://www.bright.cn/report-abuse](https://www.bright.cn/report-abuse)) 报告我们网络中的任何滥用或可疑活动。

# 概述

> Bright Data 提供 AI 就绪的网页数据基础设施，为您的模型和智能体提供实时、高质量的网页访问。无论您是在为 RAG 管道提供数据、实现智能体驱动搜索，还是获取结构化数据，Bright Data 都通过预构建集成、灵活的 API 选项以及 MCP 服务器，与常见的 AI/ML 工作流实现无缝兼容。

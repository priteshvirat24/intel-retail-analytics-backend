# 反检测浏览器集成

> 在反检测浏览器中配置Bright Data代理，用于多账户管理和隐私浏览。

反检测浏览器让您可以管理多个具有独特指纹的浏览器配置文件。添加 Bright Data 代理为每个配置文件提供不同的、受信任的 IP 地址。

# 功能

扩展中有哪些功能可用？

Bright Data 代理浏览器扩展支持数据中心和固定 IP 浏览，允许您从任何国家进行搜索。 您可以调整用户代理，自定义 DNS 配置以最大限度地提高判断能力或速度，以及设置随机 IP 切换。

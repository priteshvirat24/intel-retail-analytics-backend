# 介绍

> 使用 Bright Data Chrome 浏览器扩展，无需手动配置即可通过住宅、移动、数据中心或 ISP 代理路由流量。

设置 Chrome 使用代理网络需要一定的技术知识和配置，许多用户会觉得复杂且难以管理。使用 Bright Data 的 Chrome 浏览器扩展程序，可以让你直接在浏览器中使用 Bright Data 的代理网络，只需最少的设置和配置。在一个地方即可管理和组织所有参数，清晰且易于访问。

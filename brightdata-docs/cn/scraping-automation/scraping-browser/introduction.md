# Browser API 简介

> 了解 Bright Data 的 Browser API 如何通过强大的代理网络、浏览器自动化和全面的解封能力简化多步骤数据采集。

Browser API 是我们 [解封采集套件](/cn/scraping-automation/introduction) 的一部分，旨在简化您通过浏览器进行的**多步骤数据采集**。

您的采集代码可在我们的专用浏览器上无缝运行，利用多种代理网络（包括住宅 IP），并管理每个页面的完整解封过程，包括自定义请求头、指纹处理、CAPTCHA 验证等。

通过标准浏览库轻松访问并导航目标网站，例如 `puppeteer`、`playwright` 和 `selenium`（查看我们的[完整列表](/cn/scraping-automation/scraping-browser/faqs#哪些编程语言、库和浏览器自动化工具支持-browser-api)），以无限**规模**和无限**并发会话**提取您所需的精确数据。

### 最适用于

* 无缝浏览网站、填写表单、点击按钮、滚动加载完整页面、悬停、解决 CAPTCHA 以及更多交互操作
* 集成 `Puppeteer`、`playwright` 和 `selenium`，并灵活按需扩大或缩小活动浏览器会话数量
* 没有可靠且可扩展的内部浏览器解封基础设施的团队

# 如何开始使用 Browser API

> 按照以下步骤，在几分钟内开始使用 Bright Data 的 Browser API。设置您的代理并立即开始采集。

<Steps>
  <Step title={<a href="https://www.bright.cn/?hs_signup=1">登录</a>}>
    <Tip>
      如果您是新用户，可[免费注册](https://www.bright.cn/?hs_signup=1)并获得 \$2 奖励。添加付款信息可额外获得 \$5 奖励资金。
    </Tip>

    <Note>
      如果您已有账号，请在[此处登录](https://www.bright.cn/cp/start)。
    </Note>
  </Step>

  <Step title={<>前往 <a href="https://www.bright.cn/cp/zones">My Zones</a></>}>
    <Accordion title="在 My Zones 页面中，Browser API 下点击 Get started">
      <Warning>
        如果您已有一个活动代理，只需点击右上角的 **Add**
      </Warning>

      <Frame>
        <img src="https://mintcdn.com/brightdata/5sJgYq9iW-Vo_7rr/BrowserAPi.png?fit=max&auto=format&n=5sJgYq9iW-Vo_7rr&q=85&s=e1cb7bee8ade4e6c457dc0d0fdc803a4" alt="Get Started" title="" className="mx-auto" style={{ width:"100%" }} width="885" height="671" data-path="BrowserAPi.png" />
      </Frame>
    </Accordion>
  </Step>

  <Step title="为您的 Browser API 指定名称">
    <Warning>
      请设置一个有意义的名称，因为创建后无法更改。
    </Warning>
  </Step>

  <Step title="点击 Add">
    <Accordion title="在 “Add new zone” 页面中点击 Add">
      <Frame>
        <img src="https://mintcdn.com/brightdata/5sJgYq9iW-Vo_7rr/addbrowserapi.png?fit=max&auto=format&n=5sJgYq9iW-Vo_7rr&q=85&s=83396dea071e8039f40073f65e24ad4a" alt="Get Started" title="" className="mx-auto" style={{ width:"100%" }} width="1176" height="591" data-path="addbrowserapi.png" />
      </Frame>
    </Accordion>
  </Step>

  <Step title="开始使用您的 Browser API">
    <Note>
      您的 Browser API 区域已准备就绪！打开区域仪表板查看您的凭证，并参考我们的[配置示例](/cn/scraping-automation/scraping-browser/configuration)开始发送浏览器请求。
    </Note>
  </Step>
</Steps>

# SERP API 快速入门

> 按照这些简单步骤快速开始使用 Bright Data 的 SERP API。登录、创建代理并验证账户，即可轻松开始收集搜索引擎数据。

<Tip>
  **免费开始，无需信用卡**

  您的免费套餐每月包含 **5,000 个免费信用额度**，可用于 SERP API。无需支付方式即可创建 SERP API 并立即开始发送请求。[了解免费套餐](/cn/general/account/billing-and-pricing/free-tier)。
</Tip>

<Steps>
  <Step title={<a href="https://www.bright.cn/cp/start">登录</a>} />

  <Step title={<>进入 <a href="https://www.bright.cn/cp/zones">我的 Zones</a></>}>
    <Accordion title="在我的 Zones 页面，SERP API 下点击 Get started">
      <Warning>
        如果您已有活跃代理，只需在右上角选择 **Add**
      </Warning>

      <Frame>
        <img src="https://mintcdn.com/brightdata/S8tFtc_KJjCQxqv1/images/scraping-automation/serp-api/quick-start/get-started.png?fit=max&auto=format&n=S8tFtc_KJjCQxqv1&q=85&s=d5064de2f578affb5e50e01991eb4a58" alt="开始使用" width="846" height="911" data-path="images/scraping-automation/serp-api/quick-start/get-started.png" />
      </Frame>
    </Accordion>
  </Step>

  <Step title="为您的 SERP API 指定名称">
    <Warning>
      请为 zone 选择一个有意义的名称，zone 创建后名称不可更改。
    </Warning>
  </Step>

  <Step title="点击 Add" />
</Steps>

<Accordion title="继续前，请验证您的账户">
  如果您尚未添加付款方式，此时系统会提示您添加，以验证账户。如果这是您第一次使用 Bright Data，还会获得 \$5 启动信用额度！

  <Tip>
    此时不会收取任何费用，仅用于验证目的
  </Tip>
</Accordion>

<Note>
  不用担心，我们将在下一节 [配置您的代理](/cn/scraping-automation/serp-api/configuration) 中覆盖所有配置
</Note>

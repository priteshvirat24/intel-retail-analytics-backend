# 产品概述

Easy Scraper 是一种即插即用的解决方案，允许用户使用现成的抓取工具轻松地从各个域收集数据。

该产品通过提供直观的控制面板简化了数据收集过程，用户可以在控制面板中选择抓取工具、输入参数、设置收集偏好并以多种格式检索数据。

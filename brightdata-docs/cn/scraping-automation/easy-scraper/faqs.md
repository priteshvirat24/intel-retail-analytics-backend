# 常见问题

<AccordionGroup>
  <Accordion title="什么是 Easy Scraper？">
    Easy Scraper 是一个用户友好的数据采集工具，允许用户使用预构建的爬虫从各种在线平台收集信息。它旨在简化采集流程，使技术经验较少的用户也能轻松使用。
  </Accordion>

  <Accordion title="如何开始使用 Easy Scraper？">
    要开始使用，请登录您的账户，进入 Easy Scraper 区域，选择一个爬虫，输入参数并运行爬虫。随后您即可按照所需格式获取数据。
  </Accordion>

  <Accordion title="如何使用 Easy Scraper？">
    您可以通过选择爬虫、添加输入、必要时设置结果上限、选择数据存储位置并启动采集流程来使用 Easy Scraper。您可以在日志（Logs）标签页中监控并检索数据。
  </Accordion>

  <Accordion title="爬虫之间有什么区别？">
    每个爬虫都被设计用于从特定领域收集数据。例如，Amazon 商品爬虫用于采集商品信息，而 LinkedIn 个人资料爬虫用于收集 LinkedIn 个人资料数据。不同领域需要的输入参数及采集的数据类型会有所不同。
  </Accordion>

  <Accordion title="这些爬虫是否有任何限制？">
    某些爬虫可能会因数据源而存在限制，例如速率限制或受限的数据访问。所有限制都会显示在各自的爬虫页面上。如果在采集过程中遇到任何限制，系统会通知您。
  </Accordion>

  <Accordion title="Easy Scraper 支持哪些数据格式？">
    Scrapers 支持多种数据格式，包括 JSON、NDJSON、JSON Lines 和 CSV。您可以在请求参数中指定所需格式。
  </Accordion>

  <Accordion title="Easy Scraper 的计费方式是什么？">
    我们根据来自有效输入的交付记录数量收费。单条记录的费用取决于您的订阅计划。请查看[我们的定价方案](https://www.bright.cn/pricing/web-scraper)或您的账户详情以获取具体费率。
  </Accordion>

  <Accordion title="如何升级我的订阅计划？">
    要升级您的订阅计划，请进入仪表盘的账单页面并选择所需计划。如需进一步协助，您可以通过控制面板右上角的问号按钮 (?) 联系支持团队，或通过以下链接提交请求：[https://brightdata.zendesk.com/hc/en-us/requests/new，](https://brightdata.zendesk.com/hc/en-us/requests/new，) 也可发送电子邮件至  [support@brightdata.com](mailto:support@brightdata.com)。
  </Accordion>

  <Accordion title="Easy Scraper 的速度如何？">
    Easy Scraper 的响应时间取决于多个因素，例如目标 URL 的加载时间以及用户定义的页面交互执行时间。每个爬虫的平均响应时间指示可在各自的爬虫页面找到。

# Bright Data 的 Web Unlocker API 快速入门指南

> 快速开始使用 Bright Data 的 Web Unlocker API。按照我们的分步指南设置代理并立即开始采集数据。

<Tip>
  **免费开始，无需信用卡**

  您的免费套餐每月包含 **5,000 个免费信用额度**，可用于 Web Unlocker API。无需支付方式即可创建 Web Unlocker API 并立即开始发送请求。[了解免费套餐](/cn/general/account/billing-and-pricing/free-tier)。
</Tip>

<Steps>
  <Step title={<a href="https://www.bright.cn/cp/start">Sign in</a>} />

  <Step title={<>导航到 <a href="https://www.bright.cn/cp/zones">My Zones</a></>}>
    <Accordion title="在 My Zones 页面中，点击 Web Unlocker API 下的 Get started">
      <Warning>
        如果您已经有一个激活的代理，只需点击右上角的 **Add**
      </Warning>

      <Frame>
        <img src="https://mintcdn.com/brightdata/S8tFtc_KJjCQxqv1/images/scraping-automation/web-unlocker/quick-start/get-started.png?fit=max&auto=format&n=S8tFtc_KJjCQxqv1&q=85&s=272d304984ac5a82a86796c7322351cc" alt="Get Started" width="1157" height="888" data-path="images/scraping-automation/web-unlocker/quick-start/get-started.png" />
      </Frame>
    </Accordion>
  </Step>

  <Step title="为 Web Unlocker API 指定一个名称">
    <Warning>
      请为其选择一个有意义的名称，因为 zone 名称一旦创建将无法更改。
    </Warning>
  </Step>

  <Step title="点击 Add" />
</Steps>

<Accordion title="继续之前，请验证您的账户">
  如果您还没有添加支付方式，此时系统会提示您添加。若您是第一次使用 Bright Data，还将额外获得 \$5 的奖励额度！

  <Tip>
    请放心，此阶段不会向您收费，该步骤仅用于账户验证。
  </Tip>
</Accordion>

<Note>
  别担心，我们将在下一部分 [Configuration](/cn/scraping-automation/web-unlocker/configuration) 中介绍所有配置。
</Note>

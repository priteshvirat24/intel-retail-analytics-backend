# Product overview

> Use Bright Data Easy Scraper to collect structured data from supported sites with prebuilt scrapers configured from the Control Panel, no custom code required.

Easy Scraper is a **plug-and-play data collection solution** that enables users to quickly collect structured data from supported websites using **prebuilt scrapers**.

It eliminates the need for custom scraping logic or infrastructure. Through an intuitive control panel, users can:

* Select a ready-made scraper for a specific domain
* Provide basic input parameters
* Configure simple collection preferences
* Retrieve data in multiple download formats

Easy Scraper is designed for users who want fast results with minimal setup, making it suitable for both technical and non-technical users.

Limitations&#x20;
File size
---------

Easy Scraper supports the following file size limits:

* **Input size:** Up to **1 GB**
* **Download size:** Up to **5 GB**

For datasets larger than 5 GB, we recommend using **API-based delivery** to ensure reliable and efficient data transfer.

# Create your first SERP API

> Get started with the Bright Data SERP API (31 languages) in 3 steps: create a zone, generate credentials and send your first Google search query.

<Callout icon="badge-dollar" color="#4180f9" iconType="solid">
  **Start free, no credit card required**

  Your account gets **5,000 free credits every month**, drawn from a single shared pool across the eligible products, and SERP API requests spend from that shared pool. Create your SERP API and start sending requests immediately, no payment method needed. [Learn more about the free tier](/general/account/billing-and-pricing/free-tier).
</Callout>

<Steps>
  <Step title={<a href="https://brightdata.com/cp/start">Sign in to Bright Data</a>} />

  <Step title={<>Navigate to <a href="https://brightdata.com/cp/web_access/new">Create an API</a> page</>}>
    Navigate to **Create an API** under the **Web Access API** section in the left menu.

    <Frame>
      <img src="https://mintcdn.com/brightdata/S8tFtc_KJjCQxqv1/images/scraping-automation/serp-api/quick-start/create-an-api.png?fit=max&auto=format&n=S8tFtc_KJjCQxqv1&q=85&s=9a4572cc3a72c7d81f46eac85cc07c50" alt="Create an API" width="1772" height="984" data-path="images/scraping-automation/serp-api/quick-start/create-an-api.png" />
    </Frame>
  </Step>

  <Step title="Choose SERP API">
    Select **SERP API** and click **Continue**.

    <Frame>
      <img src="https://mintcdn.com/brightdata/S8tFtc_KJjCQxqv1/images/scraping-automation/serp-api/quick-start/select-serp-api.png?fit=max&auto=format&n=S8tFtc_KJjCQxqv1&q=85&s=d8fb2b9833f5ee8dfa506b1eac5007f1" alt="SERP API" width="3260" height="1420" data-path="images/scraping-automation/serp-api/quick-start/select-serp-api.png" />
    </Frame>
  </Step>

  <Step title="Assign a name to your SERP API">
    Enter a meaningful name. Optionally, add a short description.

    <Warning>
      **The SERP API name cannot be changed once created.**

      All other settings can be modified later. For details, see [Configure your API](/scraping-automation/serp-api/configuration).
    </Warning>

    <Frame>
      <img src="https://mintcdn.com/brightdata/S8tFtc_KJjCQxqv1/images/scraping-automation/serp-api/quick-start/config-serp-api.png?fit=max&auto=format&n=S8tFtc_KJjCQxqv1&q=85&s=ab24680607af5dd58dfd10b3b0a33329" alt="API Name" width="3260" height="1422" data-path="images/scraping-automation/serp-api/quick-start/config-serp-api.png" />
    </Frame>
  </Step>

  <Step title="Finalize API creation">
    Click **Add API**. Your SERP API is now ready to use.
  </Step>
</Steps>

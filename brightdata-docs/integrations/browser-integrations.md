# Anti-detect browser integrations

> Configure Bright Data proxies (400M+ residential IPs) in anti-detect browsers like GoLogin, MuLogin and XLogin for multi-account fingerprint management.

Anti-detect browsers let you manage multiple browser profiles with unique fingerprints. Adding Bright Data proxies gives each profile a distinct, trusted IP address.

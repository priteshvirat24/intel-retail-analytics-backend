# Browser extension features

> Overview of Bright Data's Proxy Browser Extension features: country-level browsing, IP rotation, user agent control, and DNS configuration.

What features are available in the extension?

Bright Data Proxy Browser Extension supports datacenter and residential IP browsing, allowing you to search from any country. You can adjust the user agent, customize configuration of the DNS to maximize discretion or speed, and set random IP rotation.

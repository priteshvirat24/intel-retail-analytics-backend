# Browser extension configuration

> How to configure the Bright Data Proxy Browser Extension: update zone, country, custom headers, and proxy settings from the setup page.

How can I change the extension's settings?

Open [Extension setup page](https://brightdata.com/cp/bext) and change settings such as Zone, Country, Custom Headers, or anything necessary. Click 'Apply' when done, and your extension will be updated with the new setup.
